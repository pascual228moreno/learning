## Como encontrar el ID de un agente

1. Abre la consola de Anthropic
2. Ve a la seccion de Agents
3. Haz clic en el agente
4. El ID aparece en la URL o en los detalles del agente
   (formato: agent_XXXXXXXXXXXXXXXXXXXXXXXXX)

## Como encontrar tu API Key

1. Ve a Settings en la consola
2. Busca la seccion API Keys
3. Copia la clave activa
   (formato: sk-ant-api03-XXXXXXXXXX)
