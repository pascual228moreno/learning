## 1. Sesiones impartidas (5 de 8)

### Sesión 1 — Claude + Managed Agents I
Introducción a la consola de Anthropic. Creación de los primeros agentes (Researcher, Archivist, Coordinator). Conceptos base: system prompt, rol, herramientas.

### Sesión 2 — Claude + Managed Agents II
Profundización en la orquestación de agentes. Diseño de flujos multi-agente. Configuración de herramientas y paso de contexto entre agentes.

### Sesión 3 — Claude + Managed Agents III
Agentes especializados. Orquestador central. Integración de las piezas en un pipeline funcional completo desde la consola.

### Sesión 4 — AG2 Framework + Claude Code
Paso de la consola al código. Instalación de Python, Node.js y Claude Code. Concepto de CLAUDE.md y SDD (Spec Driven Development). Pipeline AG2 construido por Claude Code sin escribir código manualmente: investigación de mercado → posts LinkedIn → revisión corporativa.

### Sesión 5 — Claude Design + Claude en el navegador ✓ (hoy, 12/06)
Sesión más amplia de lo previsto. Se cubrió:

- **Claude Design**: fundamento y base de conocimiento, creación del esqueleto de marca (posicionamiento, paleta, tipografía, voz y tono), extrapolación a piezas concretas, ciclo de corrección e iteración.
- **Trabajo agéntico aplicado a scraping de precios**: integración de un flujo agentico para recoger y comparar precios de productos en supermercados. Caso práctico con valor directo para las alumnas.
- **Claude en el navegador**: extensión instalada y evaluada. Se vieron las limitaciones reales por razones de seguridad y privacidad de datos: qué puede leer Claude en el navegador, qué datos se envían a Anthropic y en qué contextos profesionales no debe usarse.
- **Publicación de una app en Google AI Studio**: flujo completo de despliegue de una aplicación desde Google AI Studio. Análisis de costes asociados (modelo, tokens, uso esperado) para que las alumnas puedan evaluar viabilidad antes de escalar.
